# My Daily Habits

Projeto desenvolvido no Módulo 4 - Desenvolvimento Front-end com React.

## Requisitos
- Node.js compatível com a versão atual do vite
- npm

## Como executar
```bash
npm install
cp .env.example .env
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

# Funcionalidades
- cadastro e conclusão de hábitos
- persistência no navegador
- navegação por rotas
- detalhes por parâmetro de URL
- consumo de API com loading e tratamento de erro
